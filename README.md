# Grocery Store Management System

A web app for managing grocery store products and orders. The backend is built with Flask and MySQL, and the frontend is plain HTML, CSS and JavaScript.

## Features
- View, add and delete products
- Manage units of measure
- Place and view orders

## Tech stack
Python, Flask, MySQL, HTML, CSS, JavaScript, Bootstrap

## Setup
1. Install dependencies:
```
   pip install flask mysql-connector-python python-dotenv
```
2. Create a MySQL database for the project.
3. In the `Grocery Project` folder, copy `.env.example` to `.env` and fill in your own database details.
4. Start the backend:
```
   cd "Grocery Project"
   python server.py
```
5. Open `python_projects_grocery_webapp-main/ui/index.html` in your browser.
